---
title: Creating an instance
description: Create an isolated Minecraft setup with the right version, loader, memory, and location.
category: getting-started
order: 2
tags: [instances, beginner]
---

Open **Instance Library**, choose **New**, and select a Minecraft version. You can use Vanilla, Fabric, Forge, NeoForge, Quilt, or one of Refract's presets.

Choose memory conservatively; assigning more memory than the system has available can make both Minecraft and the desktop unstable. Refract warns when free RAM is below the instance allocation.

Instances isolate their mods, worlds, configuration, screenshots, and launch options. This keeps experiments and modpacks from overwriting one another.
