---
title: Importing existing data
description: Import instances, archives, worlds, and libraries from other launchers.
category: getting-started
order: 3
tags: [instances, migration]
---

The Sync panel can detect Prism Launcher, MultiMC, Modrinth, ATLauncher, CurseForge, and GDLauncher libraries. Choose **Link** to launch an instance in its existing location, or **Import** to copy it into Refract.

Refract also accepts common instance archives and Modrinth `.mrpack` files. Version 1.3 improves archive detection for layout, mod loader, and Minecraft version, and can import worlds from ZIP backups.
