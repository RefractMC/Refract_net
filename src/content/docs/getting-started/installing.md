Use the [download pages](/download/) to choose an official package. Linux and macOS can also use the project install script:

```sh
curl -fsSL https://refractmc.net/install.sh | sh
```

On Windows, run the signed x64 installer. On macOS, choose the Apple silicon build for M-series Macs or the Intel build for older hardware. On Linux, AppImage is the most portable option; Debian and RPM packages integrate with supported distributions.

> Download Refract only from refractmc.net or the official GitHub releases page.
