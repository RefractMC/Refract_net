Search [existing GitHub issues](https://github.com/RefractMC/Refract_MC/issues) before opening a report. Include your Refract version, operating system, steps to reproduce, expected result, and relevant launcher log lines.

Do not post credentials, access tokens, or private server addresses. Security vulnerabilities should follow the repository's [security policy](https://github.com/RefractMC/Refract_MC/security/policy).
