Refract is a free, open-source Minecraft Java launcher built with React, Tauri, and Rust. It keeps instances, community content, accounts, Java runtimes, worlds, servers, screenshots, and launch settings in one desktop application.

Refract is not affiliated with Mojang or Microsoft. A licensed Minecraft Java account is required for normal online play.

## What Refract manages

- Separate instances with their own versions, loaders, content, worlds, and options.
- Mods, modpacks, shaders, resource packs, and datapacks from Modrinth and CurseForge.
- Microsoft, offline, and Yggdrasil accounts.
- Automatic Java discovery and download.
- Worlds, backups, screenshots, servers, logs, and playtime.
