## Is Refract free?

Yes. The application is licensed under GNU GPL v3.0.

## Which platforms are supported?

Refract publishes Windows 10/11, macOS Apple silicon and Intel, Linux AppImage, Debian, and RPM packages.

## Can I import another launcher library?

Yes. Refract can detect and import or link libraries from Prism Launcher, MultiMC, Modrinth, ATLauncher, CurseForge, and GDLauncher.

## Where is my data stored?

Refract uses the platform application-data directory by default. You can also choose custom instance locations. Back up important worlds before changing or deleting launcher data.
