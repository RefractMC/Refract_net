description: Protect worlds and understand instance, account, and settings storage.
category: help

World rows include a backup action that writes a ZIP archive to a location you choose. Back up important worlds before changing mod loaders, removing content, updating large packs, or deleting an instance.

Do not share account vault files or full launcher-data archives publicly. Logs should be reviewed for personal file paths and private server addresses before posting.
