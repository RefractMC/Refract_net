## Session expired

Open Accounts and choose **Sign in again**. Refract validates saved sessions proactively, but Microsoft authentication may still require a fresh browser sign-in.

## A mod is incompatible

Check the instance's Minecraft version and loader. A Fabric mod will not load under Forge unless it explicitly supports it.

## The game exits immediately

Copy the crash report or launcher log, disable recently added content, restore automatic Java selection, and retry. If the issue is reproducible, open a GitHub issue with the log and exact steps.
