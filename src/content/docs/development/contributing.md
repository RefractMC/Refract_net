Read the repository's [contribution guide](https://github.com/RefractMC/Refract_MC/blob/main/CONTRIBUTING.md) before opening a pull request. Keep changes focused, run the required verification commands, and explain the player-facing behavior you changed.

For translation work, copy `locales/en.json`, name the file with a BCP 47 language tag, translate every value without changing keys, and follow the translation guide in the repository.
