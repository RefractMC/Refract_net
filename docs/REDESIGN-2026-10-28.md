# Homepage redesign, October 28, 2026

## Scope and reference

Updated the existing Astro checkout, retaining its pre-existing uncommitted work, content collections, route slugs, news feeds, canonical metadata, download guides, documentation search, and screenshot gallery. No replacement application or frontend framework was introduced. Deployment remains the existing GitHub Pages workflow; this change does not publish or change the official domain.

GDLauncher (https://gdlauncher.com/) was inspected live at desktop and mobile widths before implementation. Adopted its compact header scale, prominent platform download action, large real product preview, ecosystem area, alternating image/text feature rows, community section, and final download block. The current reference uses a split hero at its widest breakpoint; the supplied brief explicitly requested a centered Refract hero, which takes priority.

Design settings: variance 3/10, motion 2/10, density 4/10. Native Astro/CSS, the existing self-hosted Geist font, charcoal/navy surfaces, #5316D4 primary actions, and lighter purple for accessible accent text. Controls use 8px corners, screenshot and section surfaces approximately 10px. Motion is limited to hover feedback and reduced-motion-aware anchor scrolling.

## Live data

The homepage is server-rendered with dated build snapshots and progressively refreshes public GitHub and Discord data in the browser. Requests are anonymous, omit credentials, time out after eight seconds, and validate release assets and repository/guild identity. Build secrets remain server-only. The static CSP permits connections only to self, api.github.com, and discord.com.

Homepage total downloads sum every uploaded asset from every public release, deduplicated by asset ID. Pagination must complete before displaying an all-time total. This includes update manifests and updater archives, and is explicitly not a unique-player count. The pre-existing community-page installer-only metric remains distinct and unchanged.

Failed live requests preserve the dated release/repository snapshot and links, with a visible freshness explanation. Discord live failure hides ephemeral presence counts. Missing release assets link to the real release with a truthful availability label; filenames and URLs are never guessed. OS detection selects an OS-family download guide, leaving CPU architecture selection explicit.
